Laboratoire Docker et n8n - Agent IA local

Projet personnel: un agent IA qui tourne entièrement en local, sans service cloud, avec Docker, n8n, Ollama, Qdrant et Piper.

Objectif

Apprendre à créer et à administrer des agents IA avec n8n, en local, dans des conteneurs Docker. Le laboratoire met en place un workflow RAG: l’agent répond à partir de mes propres documents.

Technologies
Docker: conteneurisation de tous les services
n8n: automatisation et orchestration des workflows
Ollama: moteur IA local
Qdrant: base de données vectorielle pour le RAG
Piper: synthèse vocale locale
Ce que le laboratoire couvre
Installation et configuration de l’environnement Docker
Mise en place de n8n, Ollama, Qdrant et Piper
Indexation de documents dans Qdrant
Création d’un workflow d’agent IA avec recherche dans les documents (RAG)
Réponse vocale générée en local
Contenu du dépôt
